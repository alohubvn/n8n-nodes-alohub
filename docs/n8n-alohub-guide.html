Tổng quan

n8n-nodes-alohub là community node cho nền tảng n8n, cho phép tích hợp các dịch vụ CPaaS của Alohub vào workflow tự động hóa.

Node hỗ trợ 2 tính năng chính:

Tính năng

Operation

Mô tả

Voice

Make a Call (Click to Call)

Thực hiện cuộc gọi ra qua IP Phone

Zalo ZNS

Send

Gửi thông báo ZNS qua Zalo với template động

Lưu ý: Bạn cần có tài khoản Alohub và API Key để sử dụng node này. Liên hệ Alohub để được cấp thông tin.

Cài đặt

Cách 1 — Cài từ giao diện n8n (khuyên dùng)

  1. Mở n8n, vào Settings → Community Nodes

  2. Click Install a community node

  3. Nhập n8n-nodes-alohub

  4. Click Install → đợi cài xong

Cách 2 — Cài bằng npm (self-hosted)

Chạy lệnh sau trong thư mục cài đặt n8n:

npm install n8n-nodes-alohub

Sau đó restart n8n để load node mới.

Thiết lập Credential (API Key)

Trước khi sử dụng node, bạn cần tạo credential chứa API Key của Alohub.

  1. Kéo node Alohub vào workflow

  2. Click vào dropdown Credential → chọn Create new credential

  3. Nhập API Key — lấy từ dashboard Alohub. Liên hệ Alohub nếu chưa có.

  4. Click Save — hệ thống sẽ tự kiểm tra kết nối

Sử dụng — Zalo ZNS: Send

Gửi thông báo ZNS (Zalo Notification Service) tới số điện thoại có tài khoản Zalo.

Cấu hình

  1. Chọn Resource: Zalo ZNS Notification

  2. Chọn Operation: Send

  3. Điền số điện thoại nhận

  4. Chọn Campaign từ dropdown — hỗ trợ tìm kiếm và phân trang

  5. Template Parameters tự động load dựa theo campaign đã chọn → điền giá trị vào các trường

Cách Template Parameters hoạt động

  1. Khi bạn chọn một campaign, node tự gọi API lấy thông tin template ZNS tương ứng

  2. Các trường có sourceColumn (dữ liệu người dùng nhập) sẽ hiển thị để điền giá trị

  3. Các trường staticValue (giá trị cố định) được xử lý tự động phía server — không hiển thị trên giao diện

  4. Label hiển thị = paramName (ví dụ: customer_name), key gửi API = sourceColumn (ví dụ: name)

Lưu ý: Số điện thoại nhận phải có đăng ký tài khoản Zalo. Nếu không, ZNS sẽ gửi không thành công.

Sử dụng với AI Agent

Node Alohub hỗ trợ chế độ AI Tool — có thể dùng như một công cụ cho AI Agent trong n8n.

Cách thiết lập

  1. Kéo node When chat message received (Chat Trigger) vào canvas

  2. Kéo node AI Agent → nối từ Chat Trigger

  3. Trong AI Agent, click + tại slot Chat Model → chọn OpenAI / Claude / Gemini → tạo credential

  4. Click + tại slot Tool → tìm Alohub → chọn Alohub Tool

  5. Cấu hình Alohub Tool: chọn Resource, Operation, và dùng expression {{ $fromAI('fieldName') }} cho các trường để AI tự điền
