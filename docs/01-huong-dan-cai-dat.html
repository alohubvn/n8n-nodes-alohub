Tổng quan

n8n-nodes-alohub là community node cho nền tảng n8n, cho phép tích hợp các dịch vụ CPaaS của Alohub vào workflow tự động hóa.

Node hỗ trợ 2 tính năng chính:

Mô tả

Zalo ZNS

Send

Gửi thông báo ZNS qua Zalo với template động

Lưu ý: Bạn cần có tài khoản Alohub và API Key để sử dụng node này. Liên hệ Alohub để được cấp thông tin.

Cài đặt

Cách 1 — Cài từ giao diện n8n (khuyên dùng)

  1. Mở n8n, vào Settings → Community Nodes

  2. Click Install a community node

  3. Nhập n8n-nodes-alohub

  4. Click Install → đợi cài xong

Cách 2 — Cài bằng npm (self-hosted)

Chạy lệnh sau trong thư mục cài đặt n8n:

npm install n8n-nodes-alohub

Sau đó restart n8n để load node mới.

Thiết lập Credential (API Key)

Trước khi sử dụng node, bạn cần tạo credential chứa API Key của Alohub.

  1. Kéo node Alohub vào workflow

  2. Click vào dropdown Credential → chọn Create new credential

  3. Nhập API Key — lấy từ dashboard Alohub. Liên hệ Alohub nếu chưa có.

  4. Click Save — hệ thống sẽ tự kiểm tra kết nối
