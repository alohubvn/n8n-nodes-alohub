Voice: Click to Call

Thực hiện cuộc gọi ra (outbound) bằng cách kết nối số điện thoại khách hàng với IP Phone nội bộ thông qua Alohub.

Yêu cầu: Đã cài đặt node n8n-nodes-alohub và thiết lập API Key credential. Xem Hướng dẫn cài đặt nếu chưa thực hiện.

Cấu hình

  1. Kéo node Alohub vào canvas

  2. Chọn Credential: Alohub account đã tạo

  3. Chọn Resource: Voice

  4. Chọn Operation: Make a Call

  5. Điền các tham số bên dưới

Ví dụ Workflow

Workflow đơn giản — Gọi thủ công

[Manual Trigger] → [Alohub: Voice > Make a Call]
                     Phone Number: 0912345678
                     IP Phone: 6688

Workflow nâng cao — Gọi từ danh sách Google Sheets

[Schedule Trigger] → [Google Sheets: Get Rows] → [Alohub: Voice > Make a Call]
                                                    Phone Number: {{ $json.phone }}
                                                    IP Phone: {{ $json.extension }}

Sử dụng với AI Agent

Click to Call có thể được dùng như một công cụ cho AI Agent — AI sẽ tự trích xuất số điện thoại và extension từ câu chat.

Thiết lập

  1. Kéo node When chat message received → nối tới AI Agent

  2. Thêm Chat Model (OpenAI / Claude / Gemini)

  3. Thêm Tool: chọn Alohub Tool

  4. Cấu hình Alohub Tool:
